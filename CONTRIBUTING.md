# Contributing

Thanks for helping. The most useful contributions are fixes to the timing engine, layout parts that a real video needed, and clearer docs.

## Ground rules

- **npm only.** Use `npm ci`, and commit the updated `package-lock.json` when you change dependencies. Do not add a `yarn.lock`, `pnpm-lock.yaml` or `bun.lock`. Keep every `remotion` and `@remotion/*` package on the same exact version.
- **Tests are required.** Every change comes with a Vitest test, including the failure a user would hit. Tests never call the network: stub `fetch`, as `test/narrate.test.ts` does. `npm run coverage` must stay at 90% of lines or more; the only exclusions are listed with their reasons in `vitest.config.ts`. A change to how a scene looks also comes with a review sheet in the PR (see below).
- **Errors say what to do.** A failure a user can fix throws a `KitError` with the next step as its hint.
- **No generated voice audio in the repo.** The example ships captions-only timing. Voiced MP3s and their cache files belong to whoever generated them and make the repo heavy, so `.gitignore` keeps them out.
- **Nothing to license.** Sound effects are generated by `scripts/sfx.sh`. Fonts come from Google Fonts at render time. Do not add music, stock images or font files.
- **Made-up content only.** Example scripts use invented people and companies. Never put a real customer, phone number, address or API key in a script, test, issue or screenshot.
- **One new part, one real use.** A new layout part is used by the example video in the same PR.

## Workflow

```bash
npm ci
npm run check   # lint, typecheck, tests with coverage, bundle, licence check
npm run smoke   # renders both review sheets and a thumbnail into out/smoke
```

Attach `out/smoke/sheet.png` to any PR that changes how a scene looks.

## Developer Certificate of Origin

Please sign off every commit, certifying the [Developer Certificate of Origin 1.1](https://developercertificate.org/):

```bash
git commit -s -m "Hold the end card longer on the wide cut"
```

That adds `Signed-off-by: Your Name <you@example.com>` from your git identity. A maintainer checks for it before merging and will ask you to add it if it is missing.
